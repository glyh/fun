# Review of the ideas catalogue against `quill` (2026-10-01)

This is a judgement pass over the nine axis docs in this directory, cross-checked against
`docs/STATUS.md` (authoritative) and `docs/wayfinder/quill-design-map.md`. It is not a new
catalogue and it decides nothing — the deciding lives in `docs/wayfinder/`. It records which
collected ideas are worth acting on, which sharpen an open question, and which confirm a
rejection already made, so a future session does not re-derive the shortlist.

**Method.** The nine axis docs (~12.6k lines, ~200 entries) were digested entry-by-entry in
three parallel passes; `STATUS.md` and the design map were read directly. The "Bearing on `quill`"
lines are the catalogue's own claims — the catalogue warns some may be stale — and were
spot-checked against `STATUS.md` and the map, not all re-verified against the code. The
corpus's biases (two subreddits, hobby over-representation, score = agreement not correctness)
apply throughout; a high score is not evidence an idea works.

## Actually useful — cheap, aligned with decided directions

1. **A pipe operator `|>`** (`syntax-and-parsing.md`). Genuinely new, zero compiler change:
   an order-group relation plus a `pub infix` prelude template — exactly Stage 11's
   library-demotion pattern. `quill`'s order-group rule means the pipe's interaction with every
   other operator is *declared*, not guessed. The corpus's leading-dot variant (Quartz) is
   research; plain `|>` is widely shipped. The one thing to get right is declaring where it
   sits relative to `->` and function application.
2. **Doc examples generated from the program** (`tooling-and-diagnostics.md`). `std/` has no
   doc comments and the conformance runner already exists. Writing examples in `std/` doc
   comments and running them through the existing `--file` mode turns documentation into tested
   behaviour — the same "one source of truth" rule the suite already enforces, no new machinery.
3. **Graydon's ten constraints as an audit** (`modules-and-abstraction.md`). Free, no code:
   `quill` has already ruled first-class-ness (yes), separate compilation (units base-anchored),
   recursion (import cycles are errors), generativity (applicative-by-purity). Running the
   checklist against the open `design-private-type-visibility-model` ticket would make the
   opacity row's decision easier.
4. **Stable error codes with a `--explain` lookup** (`tooling-and-diagnostics.md`). Genuinely
   new, lands on the open Stage 12 ticket, and is the first thing any LSP/REPL consumer needs.
   Blocked on a non-fatal diagnostic channel that does not exist yet — note it as a
   prerequisite, not a now.

## Sharpens an existing decision

5. **Evidence passing for effect routing** (`effects-and-handlers.md`). The domain model
   already names it as an allowed alternative ("the port may route by evidence instead; the
   observable rule is the same"). The corpus shows it research-shipped (Koka, EvEff). It does
   not change semantics, but it is a live *cost* decision — keep it explicitly named rather
   than letting it fade.
6. **The weirdness budget** (`design-philosophy-and-process.md`). The corpus's adoption side
   has the better evidence — unfamiliar syntax gets rejected before the design is evaluated.
   `quill` has already spent on three unintroduced conventions (case-decides-a-pattern's-role,
   `^name`, reserved keywords). This revises nothing; it is a caution for the "surface syntax
   after the macro model settles" fog item.
7. **REPL as a language-design contract** (`tooling-and-diagnostics.md`). Sharpens the
   first-class-API fog: `quill` already has one evaluator shared by checker and runner, so the
   cost of a REPL moves to *session state* (what the `Context` and accumulated opens are when
   the next input elaborates), not a second implementation. Worth writing into the fog item.

## Confirms a recorded rejection

8. **Multi-shot continuations** — nobody ships them with unrestricted mutation; the resource
   objection is concrete and unrebutted. The E7 rejection is the corpus's consensus.
9. **Green threads as substrate** — the entry itself notes stackful green threads reintroduce
   a native stack per object-level call, colliding with the `Kont`-frame rule.
10. **The census bottom** — NbE (1 thread), de Bruijn (2), decision trees (6): `quill` already
    lives at the settled-technique end. That is the "what should I just do" confirmation, not
    a gap.

## Skipped

Algebraic subtyping (research-only; collides with convertibility-as-equality and type-case),
gradual typing (unwanted), comptime blocks (would land in the library-vs-compiler fog),
hash-consing (nominal identity is applicative-by-purity — a real obstacle), flat
index-addressed trees (no middle end to motivate it).
